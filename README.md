\# ⚓ 聖瑪利亞號 · 遺骸



> \*「1521年。聖瑪利亞號已經在無風帶漂流了十一天。淡水配給減半，每個人心裡都藏著秘密。昨夜，殺戮開始了。一本被詛咒的古籍正在吞噬全船。」\*



\*\*《聖瑪利亞號的遺骸》\*\* 是一款受 TRPG 與克蘇魯神話啟發的單人敘事推理遊戲。你將扮演一名被困在幽靈船上的船員，白天搜查線索、質問倖存者，黃昏進行審判，夜晚則親眼目睹深淵如何挑選下一個祭品。



\---



\## 🎲 遊戲特色



\- \*\*動態命案現場\*\*  

&#x20; 15 本古籍對應 15 種殺人法則。每一具屍體的現場描述都由程式根據古籍、房間、受害者人格、兇手感染度即時生成，絕不重複。



\- \*\*17 位有靈魂的船員\*\*  

&#x20; 每個人都有自己的背景、秘密、恐懼與人際關係。他們會自主移動、爭吵、崩潰，甚至在你沒注意時成為模仿犯。



\- \*\*深度角色扮演\*\*  

&#x20; 八種人格法則（虔信者、底層水手、傲慢貴族……）強迫你「活成你的角色」。違反法則將承受壓力懲罰，但也可能獲得獨特的劇情分支。



\- \*\*約束圖譜推理\*\*  

&#x20; 將收集到的古籍殘頁、死者日記、嫌疑人證詞拖曳至圖譜中，驗證「死者—法則—嫌疑人」的邏輯鏈是否閉合。



\- \*\*審判政治博弈\*\*  

&#x20; 黃昏時你必須投票處決一人。你可以拉票、抹黑、結盟、自辯，但記住——處決無辜者會讓全船陷入瘋狂，深淵可能附身第二個人。



\- \*\*零外部依賴，單檔發佈\*\*  

&#x20; 純 HTML + React + Tailwind，無後端、無資料庫。下載即玩，甚至可以在沒有網路的環境中執行。

\## 🧭 遊戲流程



1\. \*\*序幕\*\*：選擇詛咒的起源（古籍打撈／詛咒遺物／異端祭祀）。

2\. \*\*身分揭曉\*\*：你將隨機成為 17 名船員之一，獲得專屬背景與扮演法則。

3\. \*\*白天\*\*：消耗 8 點 AP 搜查房間、質問 NPC、建立羈絆或暗中觀察。

4\. \*\*黃昏\*\*：審判時刻。投票處決你認為的真凶。

5\. \*\*夜晚\*\*：深淵附身某人並殺死另一人。如果你處決了無辜者，今晚可能出現第二具屍體。

6\. \*\*循環直到\*\*：找出所有真凶、全船覆沒、或你的理智歸零。

\## 📖 核心機制說明



| 系統 | 說明 |

| :--- | :--- |

| \*\*AP 行動點\*\* | 每日 8 點（存活獎勵 +1）。搜查、質問、深入交談、政治行動均消耗 AP。 |

| \*\*壓力值\*\* | 0-100。高壓力會使 NPC 證詞不可信，甚至成為模仿犯。玩家壓力過高將影響檢定難度。 |

| \*\*感染度\*\* | 0-5。被附身者或待在命案現場的人會累積感染。感染越高，越容易成為深淵的容器。 |

| \*\*扮演法則\*\* | 你抽到的角色有一條必須遵守的規則（例如「每天必須祈禱一次」）。遵守可獲得獎勵，違反則受罰。 |

| \*\*模仿犯\*\* | 極度高壓且傲慢／冷酷的 NPC，可能為了私怨模仿古籍手法殺人。現場會有破綻，約束圖譜會提示。 |

| \*\*雙殺容錯\*\* | 第一次處決錯誤有 50% 機率觸發雙殺，第二次必定觸發。這是對盲目投票的懲罰，也是絕望感的來源。 |
